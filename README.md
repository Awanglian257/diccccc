# 健康管家完整程序 · 2026-11-21

包含最新单文件前端、DeepSeek 后端、食物数据、本地处理工具、Windows 启动脚本和测试代码。运行不需要 npm install。

## Windows 使用

1. 将整个压缩包解压到“桌面\aigc”或其他文件夹，不要在压缩包中直接启动。
2. 安装 Node.js 20.19 或更高版本（推荐 Node.js LTS）。
3. 双击“配置DeepSeek.bat”，在打开的 server/.env 中填写 DEEPSEEK_API_KEY，保存关闭。没有密钥也能使用本地记录功能。
4. 双击“测试DeepSeek连接.bat”，检查模型连接。
5. 双击“启动健康管家.bat”，保持终端窗口开启，在浏览器打开 http://127.0.0.1:8787 。
6. 要用云端模型，在“AI 健康助手”中勾选“使用在线 AI”，再开始处理。

如果中文脚本文件名不便使用，可双击 START.bat 启动，CONFIGURE.bat 配置。

## 配置要点

- 真实密钥仅放 server/.env，本包不包含真实密钥或已保存的个人健康记录。
- AGENT_PUBLIC_HOST 在本机使用时留空，不用填写网址。
- 默认端口为 8787，HOST 为 127.0.0.1。更改配置后重启服务。
- 通过 localhost / 127.0.0.1 打开才能连接本机后端；直接双击 index.html 只适合本地界面体验。
- 麦克风按钮需要浏览器提供语音识别功能并获得麦克风授权。识别服务是否可用取决于浏览器和网络。

## 记录和升级

饮食、体重和身体基准保存在当前浏览器的网站存储中，不写入这个压缩包。保持原来的浏览器、主机名和端口可继续使用原本机记录。
线上 chatgpt.site 与本机 127.0.0.1 属于不同网站，记录不会自动同步。请先在旧页面使用数据导出功能备份，再在新页面导入。
覆盖升级前备份旧程序和 server/.env，不要删除旧浏览器数据。本包不会自动清空记录，也不会包含你原来的 API Key。

## macOS / Linux

在解压目录运行 sh start.sh；或者 npm start。
先将 server/.env.example 复制为 server/.env，填写密钥后启动。

## 目录

- index.html：完整、图片内嵌的前端。
- server/：本机服务、DeepSeek 接入、食物数据与配置模板。
- agent-core.js：前后端共用的处理逻辑。
- agent-ui.js、agent-ui.css、frontend-source/：前端源代码参考；运行入口使用已编译进 index.html 的代码。
- tests/、server/test.js：测试代码。

## 检查

npm test：本地与模拟模型测试，不会调用真实付费模型。
npm run check:deepseek：使用你本机配置的密钥检查 DeepSeek，可能产生少量 API 费用。
浏览器自动化测试需要自行安装开发依赖和 Chromium。
本次打包未配置真实 DeepSeek 密钥，真实连通性需要在你本机完成配置后检查。

## 第二阶段质量修复（2.1.1）

日期业务范围统一为 1900-01-01 至 2200-12-31。普通保存基准保留阶段起始日；“重新开始阶段计划”经确认后才重置日期，饮食和体重历史保留。

录入上限用于防止误输入，不是推荐摄入量：单项重量最多 5000g、热量 10000 千卡、每种宏量营养 2000g、非克单位数量 1000；每日实际合计最多 30000 千卡、20000g 重量、每种宏量营养 6000g；额外油最多 300g、酱料热量 3000 千卡。超出时不写入。未知单位须称重填写 g；已有参考份量仍属于估算。

修改自由文字餐食身份/热量后，旧营养信息标为待补，不用旧食物的数值充当新食物数值。组合餐成功提交后可点“再记一份”明确追加相同餐食。

TDEE 校准关联窗口内实际记录与体重依据。依据变化时旧校准仅作为历史参考；没有依据指纹的旧版校准需重新校准。页面刷新会将未完成任务摘要标记为中断，不自动应用旧结果；远程任务可能继续运行，但不保证恢复，服务端重启会使旧会话过期。

开发验收：先运行 `npm ci` 安装固定测试依赖，再运行 `npm test`、`npm run test:browser`、`npm run test:phase2`、`npm run test:acceptance`、`npm run evaluate`。浏览器测试需要安装 Chromium，或通过 CHROMIUM_PATH 指定路径（Linux 默认探测 /usr/bin/chromium）。可用 `npx playwright install chromium` 安装浏览器；真实模型测试仍需密钥与授权。
